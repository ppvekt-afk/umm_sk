# Routing recipes + two worked briefs

## "I need X" → route (verify-quarterly; pick by job, then current tool)
- **B-roll for a Reel/Short (cinematic cutaway)** → generative: Veo 3.1 (all-round + native audio),
  Kling 3.0 (4K value), Runway Gen-4.5 (tight camera control). Prompt craft → veo-3. Keep clips short.
- **Faceless talking-head explainer** → avatar: HeyGen / Synthesia (heygen, forthcoming). Add VO from
  ElevenLabs (ai-voiceover, forthcoming) only if not using the avatar's own voice.
- **Narration over slides/footage** → voiceover: ElevenLabs (ai-voiceover, forthcoming).
- **Turn a long video into Shorts + sound-off captions** → clip+captions: Opus Clip / CapCut /
  Submagic (captions-and-clipping, forthcoming). Powers youtube-shorts and the Shorts→long funnel.
- **Atmospheric / nature / HDR mood shot** → Luma Ray3.
- **Fast, cheap concept test before committing** → Pika / Hailuo / Luma, then finalize on Veo/Kling.
- **A real product, place, or person you have** → don't generate it. **Film it** (see below).

## The default that saves the most trust: film it instead
Generated footage of **real things you actually have** (your product, cafe, team) reads as fake and
undercuts trust and originality signals. **Generate B-roll for what you can't film** (impossible,
expensive, abstract); **film the proof** for everything real. Generated clips stay as short cutaways.

## Worked brief 1 — blunt indie-founder voice (generative B-roll for a Reel)
```
JOB: generative B-roll (cutaway, ~3s)
SUBJECT/ACTION/SETTING: a single coin dropping into a clean glass jar; tidy kitchen counter
LIGHT+MOOD/CAMERA/ASPECT/DURATION: soft morning light, calm; slow push-in; 9:16; 3s
AUDIO: native SFX (coin clink) — Veo can do this in one pass
BRAND: muted, tidy palette (brand-profile)
ROUTE: generative -> Veo 3.1 (native audio) | Kling 3.0 if cost matters -> veo-3 for the prompt
DISCLOSURE: "AI-generated B-roll" in caption; YouTube Altered-Content if used on Shorts
NOTE: the messy-spreadsheet shot is screen-recorded, not generated (real proof).
```

## Worked brief 2 — warm studio voice (faceless explainer)
```
JOB: avatar talking-head (~30s) + VO
SUBJECT/ACTION/SETTING: friendly presenter, calm desk background, explaining the 30% tax rule
LIGHT+MOOD/CAMERA/ASPECT/DURATION: warm, soft; static medium; 9:16; ~30s
AUDIO: ElevenLabs VO (warm, unhurried) OR the avatar's built-in voice
BRAND: soft palette, low-pressure tone (voice-builder)
ROUTE: avatar -> HeyGen/Synthesia (heygen, forthcoming) ; VO -> ElevenLabs (ai-voiceover, forthcoming)
DISCLOSURE: on-screen "Created with an AI presenter"; TikTok auto-discloses; EU AI Act
NOTE: consented/owned avatar only — never a real non-consenting person's likeness.
```

Both: read brand-profile + voice-builder first; portable brief (no vendor lock-in); generated clips
are cutaways the human assembles; finished video → scheduling-and-queue → WoopSocial; AI disclosed.
Consumers of these briefs: reels-script (veo-prompt-pack), tiktok-script, youtube-shorts,
youtube-long-form, cross-platform-repurposing.
