# The PINS framework — build an evergreen traffic engine

Stop treating Pinterest like social media. It's a **visual search engine** where keyword-optimized,
fresh, vertical pins **compound into evergreen traffic.** PINS is the 2026 engine: optimise for
discoverability + outbound clicks, not in-the-moment engagement.

## P — Position for search
- **Keyword research first** (Pinterest Trends/Predicts, autocomplete, related pins): long-tail,
  high-intent, **semantic** phrases. Clarity beats cleverness.
- Put keywords in **pin title, description, board name, alt text, image file name.** Build **boards as
  keyword-themed clusters** under one pillar at a time. (Underlying discipline: `social-seo`.)

## I — Images that stop + signal
- **Vertical 2:3 (1000×1500)** — other ratios are penalized. Add a **keyword text overlay** so the pin
  reads as a clear search result *and* stops the scroll.
- Clean, on-brand visuals (brand-profile). **Video pins (9:16, 6–15s)** for ~2× engagement; **static
  pins** for traffic. Design assets via `image-prompt` → `ideogram`/`imagen`.

## N — New designs, consistently
- **Fresh is the #1 rule.** Make **3–5 visually distinct designs per destination** (not repins);
  fresh designs drive ~90% of traffic.
- Pin **steadily (3–10/day; 3–7 per cluster/week)**; **space ~72h between pins to the same URL**
  (spam filter). Consistency the algorithm can anticipate beats random bursts.

## S — Send traffic + sustain seasonally
- **Link out** to a **relevant** page (not the homepage) — Pinterest is the rare platform that rewards
  outbound links. Use **static pins** for clicks (Idea Pins don't link).
- **Evergreen library + seasonal waves launched 45–90 days early.** It's a **long game (3–6 months to
  traction)** that then compounds. Read native analytics; **repeat what earns clicks.**

## The Pinterest brief a request should fill
```
PILLAR + CLUSTER: one pillar; the keyword-themed board(s)
KEYWORDS: long-tail/semantic from Pinterest Trends/autocomplete
PINS: 3–5 distinct 2:3 designs per destination; title+desc+alt+filename keyworded
FORMAT: static (traffic) / video 9:16 6–15s (engagement) / idea (audience, no link)
LINK: relevant destination page (not homepage)
SCHEDULE: 3–10/day, 72h between same-URL; seasonal 45–90 days early
MEASURE: native Pinterest Analytics (outbound clicks/saves/impressions); repeat winners
```
