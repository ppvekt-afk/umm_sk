# Iris SMM Bot

SMM-директор Айрис — Telegram бот для управления контент-стратегией, постами, анализом и трендами.

## Навыки
Бот использует навыки из репозитория [social-media-skills](https://github.com/social-media-skills/skills). При запросе автоматически подбирается подходящий навык.

## Деплой на Render
1. Создайте репозиторий на GitHub.
2. Подключите его к Render.
3. Добавьте переменные окружения: `TELEGRAM_TOKEN`, `OPENROUTER_API_KEY`.
4. Готово.
